# Historique des demandes et décisions

Projet démarré le 2026-11-05 dans une session Claude (claude.ai), repris ensuite par Claude Code.

## Cadrage initial (QCM demandé par l'utilisateur avant toute action)
- Périmètre : armure (+ bonus de set), armes, bijoux / anneaux, arbre de compétences.
- Contenu : **fin de jeu uniquement**.
- Fonctions : totaux en direct, comparaison de deux builds, sauvegarde / partage, builds prédéfinis.
- Langue : **français**.
- Constat après recherche : la 1.0 n'a **pas de bonus de panoplie** → affiché clairement plutôt qu'inventé.

## Décisions techniques
- Page unique autonome (contrainte Artifact) ; sources découpées dans `src/` et réassemblées par `scripts/build.mjs`.
- Interface 2.0.0 (décision n° 27, qui remplace les panneaux de la n° 25 et « Ma classe » de la n° 26) : une page, colonne de gauche (points, objectifs, pourquoi, gemmes) et arbre à droite ; `localStorage` ne sert plus qu'aux builds enregistrés.
- Objectifs (décision n° 27) : combo imposé = étapes dans l'ordre, chemin le moins cher, arrêt au premier achat trop cher ; secondaire sur les points restants ; nœuds imposés verrouillés, ajouts libres ; ordre et raisons = choix du simulateur.
- Objectifs optimisés (décision n° 31) : contenu d'un build de la communauté (`src`) ou du simulateur ; ordre des éléments de chaque étape calculé hors ligne (moindre coût à 212 pts, puis aire d'avancée), jamais dans la page ; ordre des étapes = choix du simulateur.
- Ajouts (décision n° 30) : le combo est recalculé avec vos ajouts (`b.ad` : vos nœuds gratuits pour lui, vos rangs au-dessus d'un nœud imposé sans effet sur lui, en plus du budget) ; segment `-a` dans le lien ; ajout compté par une étape = imposé, sauf si le combo ne l'aurait pas sans lui ; anciens liens recalculés avec un message s'il y gagnent.
- Compétences et gemmes en français, le nom anglais suit en italique (objets et ennemis, décision n° 22 : supprimés en 2.0.0).
- Équipement (armes, armures, anneaux, perks) : retiré en 2.0.0 (décision n° 27) ; seuls les codes FZ.items / FZ.slots restent, pour relire les anciens liens.
- Code de partage dans le hash (`#b3-…`, segment `-o` des objectifs en 2.0.0), lisible sans serveur ; tables figées `FZ` (ajout en fin seulement) pour que réordonner ou ajouter des données ne casse aucun lien.
- Tracé de l'arbre = fichiers du jeu (PinDrop) ; la Flamme est un nœud logique non dessiné ; coût identique à chaque rang et liaisons non orientées signalés comme déductions.
- Les hypothèses sont signalées comme telles dans l'interface (étiquette « hypothèse » sous l'explication du combo, pied de page).
